# Backend – Qui a balancé ?

1. `composer install` (si le dossier `vendor/` manque)
2. Importer `database.sql` (crée la base `social_secret_game` et les 4 tables)
3. Vérifier `config/database.php` (hôte, utilisateur, mot de passe)
4. Lancer depuis ce dossier : `php -S localhost:8000`
   → l'API répond sur http://localhost:8000/api/*.php
